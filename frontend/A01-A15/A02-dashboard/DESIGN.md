# A02 — Dashboard điều hành

- **Schema liên quan:** orders, product_offers, warranty/RMA data if implemented
- **Nguồn dữ liệu:** chỉ API/backend có thể cung cấp dữ liệu thực tế.
- **Quy tắc:** Chỉ số doanh thu, đơn hàng, tồn kho, RMA phải tính từ dữ liệu thật; khi chưa có dữ liệu dùng trạng thái rỗng/loading, không gắn số mẫu như số thật.
- **Trạng thái:** giao diện khung; chưa kết nối backend.
