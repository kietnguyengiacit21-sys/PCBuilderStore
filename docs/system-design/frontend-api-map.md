# Bản đồ màn hình frontend → REST API → schema

## Quy ước trạng thái

30 màn được lập bản đồ từ HTML hiện tại: C01–C08, C10–C12, C17; A01–A05, A07–A10, A12; B01–B08. `B06_corrected_HTML_reference` là bản tham chiếu trùng nội dung, không phải route riêng.

**Tình trạng backend ở mọi hàng dưới đây: chưa có.** Trang, nút, form, mock data và `data-requires-backend` chỉ chứng minh UI/ý định UX; không phải API đang chạy. Cột API là route đề xuất để review.

| Màn | Năng lực UI hiện có / dữ liệu minh họa | API đề xuất | Bảng 35-table liên quan | Giới hạn cụ thể |

## Tính năng có giao diện nhưng không được ánh xạ thành API lưu trữ

Không có schema để lưu: wishlist/mua-sau, mã giảm giá, sổ địa chỉ, OTP/reset-token, VAT invoice, hàng hóa serial/warranty claims, RMA, lịch sử vận chuyển, refund, thông báo nhận hàng, CSV import history, audit log, saved comparison hoặc permission granularity. Cũng không có adapter payment/giao vận, image storage hoặc API đã được triển khai.
