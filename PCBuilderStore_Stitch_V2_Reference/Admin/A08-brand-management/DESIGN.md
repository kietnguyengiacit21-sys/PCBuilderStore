## Brand & Style

The design system embodies an elite, light-first aesthetic for high-end boutique computing, merging the precision craftsmanship of architectural luxury with the bleeding-edge performance of custom silicon. Moving deliberately away from the exhausted, aggressive matte-black tropes of legacy gaming hardware, this visual language champions luminous pearl whites, hyper-refined lilac undertones, and crystalline violet-spectrum micro-details. The experience mirrors high-precision laboratory engineering—reminiscent of cleanroom fabrication, satin-anodized white aluminum chassis, and pristine liquid-cooling loops.

The target audience encompasses high-net-worth enthusiasts, professional esports competitors, computational artists, and boutique workstation connoisseurs who value aesthetic refinement as highly as thermal dynamics and raw frame rates. The interface evokes immaculate order, frictionless precision, tactile confidence, and uncompromising luxury. Every transition, border highlight, and typography pair exists to present multi-thousand-dollar desktop configurations with the reverence typically reserved for haute horlogerie.

## Colors

The palette operates under a high-luminosity, chromatic-clean philosophy. Light is structural rather than ornamental.

- **Primary (`#7c3aed` - Royal Tech Violet):** Anchors focal interactive drivers, critical action confirmations, active hardware configuration tabs, and luminous state indicators.
- **Secondary (`#d97706` - Radiant Champagne Gold):** Reserved for elite tier status indicators, benchmark trophy distinctions, custom-loop artisan badges, and premium financing terms.
- **Tertiary (`#6366f1` - Hyper-Spectrum Indigo):** Drives secondary interactions, system bus telemetry graphs, diagnostic monitors, and auxiliary filter pills.
- **Neutral (`#1e1b4b` - Sleek Slate Violet):** Delivers razor-sharp, zero-bleed text contrast across pristine pearl backgrounds, eliminating visual fatigue while avoiding stark achromatic black.
- **Surfaces & Tiers:** 
  - Base Canvas: `#f8f7fc` (Soft Lavender Mist).
  - Elevated Container Cards: `#ffffff` (Pure Pearl White) layering over `#f0edf9` (Subtle Structural Violet).
  - Outlines & Separators: Low-friction frosted lilac `#e2e0f4` and translucent glass violet `rgba(221, 214, 254, 0.40)`.

## Typography

The type system blends contemporary, humanist-geometric clarity (**Plus Jakarta Sans**) for primary storytelling and user interfaces with cold, mechanical telemetry fonts (**Space Grotesk**) for technical hardware specifications, benchmark outputs, clockspeeds, and SKU identification.

- **Header Treatment:** High visual density, tight negative tracking, and substantial weights ensure flagship rigs read like limited-edition concept supercars.
- **Technical Readouts:** Clock rates, thermals, wattage requirements, and memory timings exclusively use `label-tech-*` roles to infuse an authentic engineering rigor into e-commerce product matrices.
- **Readability Rules:** All paragraphs maintain an open line-height (`1.5` to `1.6`) set in `#1e1b4b` at varying opacity levels (100% for primary data, 72% for explanatory subtext) to ensure instantaneous scannability without visual strain.

## Layout & Spacing

The layout operates on a disciplined 12-column responsive fluid grid that morphs into a 4-column module on mobile viewports.

- **Desktop (1280px and above):** 12 columns, `margin: 3rem`, `gutter: 1.5rem`. Max container bound locked at `1440px` to maintain optimal viewing angles for multi-angle 3D product visualizers and part-compatibility matrix screens.
- **Tablet (768px – 1279px):** 8 columns, `margin: 2rem`, `gutter: 1.25rem`. Complex builder stages automatically stack into a dual-pane workspace: visualizer top/left, specs drawer bottom/right.
- **Mobile (below 768px):** 4 columns, `margin: 1.25rem`, `gutter: 1rem`. High-priority elements use sticky bottom command bars for real-time pricing and compatibility status.
- **Rhythm:** Spacing follows strict structural multiples. `space-md` (16px) establishes standard component padding; `space-xl` (40px) and `space-2xl` (64px) dictate structural separation between hardware categories and performance benchmarking panels.

## Elevation & Depth

Depth is established through translucent chromatic glassmorphism paired with high-radius, ultra-diffused ambient violet shadows rather than heavy drop shadows.

- **Surface Layer 0 (Canvas):** Solid `#f8f7fc` base with soft, ambient radial gradients of `#f0edf9` mapped to highlight regions.
- **Surface Layer 1 (Standard Card / Grid Tile):** Solid `#ffffff` backdrop with a hairline border (`1px solid #e2e0f4`) and an ambient tinted shadow: `box-shadow: 0 4px 20px -2px rgba(124, 58, 237, 0.04), 0 2px 6px -1px rgba(30, 27, 75, 0.02)`.
- **Surface Layer 2 (Interactive Floating Panel / Hover State):** Semi-opaque `#ffffff` (94% opacity) backed by `backdrop-filter: blur(16px)` and illuminated borders: `1px solid rgba(221, 214, 254, 0.80)`. Ambient elevation: `box-shadow: 0 12px 32px -4px rgba(124, 58, 237, 0.08), 0 4px 12px -2px rgba(30, 27, 75, 0.03)`.
- **Surface Layer 3 (Modals / Configurator Flyouts / Pinned Summary):** Translucent pearl glass (`rgba(255, 255, 255, 0.92)`), `backdrop-filter: blur(24px)`, encased in a dual-line pseudo border mimicking chamfered aluminum, lifted by `0 24px 48px -8px rgba(124, 58, 237, 0.12)`.

## Shapes

The design system employs a refined radius scale (`roundedness: 2`, equating to 0.5rem / 8px for micro controls, 1rem / 16px for standard hardware cards, and 1.5rem / 24px for flagship containers). 

This balanced curvature communicates consumer electronic precision—echoing the laser-cut corner profiles of premium unibody PC cases and GPU backplates. Pill formats are strictly restricted to telemetry tags, stock status indicators, and active hardware specification badges.

## Components

### Buttons
- **Primary Action (Build Now / Add to Cart):** Deep violet gradient fill (`linear-gradient(135deg, #7c3aed, #6366f1)`), sharp white text, `border-radius: 0.75rem`, subtle micro-glow (`box-shadow: 0 4px 14px rgba(124, 58, 237, 0.35)`). Active click depresses by 1px with no color inversion.
- **Secondary (Customizer Step / Quick View):** `#ffffff` solid background, `1px solid #e2e0f4`, text color `#1e1b4b`. On hover, the border transitions to `#7c3aed` with a soft `#f0edf9` background wash.
- **Tier Highlight / VIP Edition:** Solid champagne gold accent (`#d97706`), text `#ffffff`, glowing with `rgba(217, 119, 6, 0.25)`.

### Chips & Badges
- **Specification Chips (RAM, VRAM, TDP):** Set in `label-tech-sm`, height 24px, pill-radius (`9999px`), background `#f0edf9`, text `#312e81`, border `1px solid #ddd6fe`.
- **Benchmark Performance Badges:** Champagne Gold pill (`rgba(245, 158, 11, 0.12)` background, text `#d97706`, border `1px solid rgba(245, 158, 11, 0.30)`), indicating 4K Ultra 144+ FPS certification.

### Input Fields & Search
- Inputs use `#ffffff` backgrounds with an inset structure: `1.5px solid #e2e0f4`, `border-radius: 0.5rem`, padding `0.75rem 1rem`. Focus state triggers an immediate crisp glow: `border-color: #7c3aed`, outline `3px solid rgba(124, 58, 237, 0.12)`.
- Numeric Steppers (Wattage selection, RAM stick quantities) integrate bespoke micro buttons with monospaced `Space Grotesk` counter centers.

### Checkboxes & Radios
- Selection rings maintain an outer boundary of `#ddd6fe`. Upon selection, the interior floods with `#7c3aed`, framing an inset pearl-white dot or custom vector checkmark. 
- Component selection rows inside the PC configurator utilize whole-surface radio cards that subtly scale and illuminate with a `1.5px solid #7c3aed` border upon selection.

### Cards (Component & System Pre-builts)
- Base background `#ffffff`, border `1px solid #e2e0f4`, padding `1.5rem`.
- Features an integrated top header for hardware categorisation, an expansive transparent PNG visual zone with soft ambient under-glow, followed by a segmented spec table and a fixed sticky footer for compatibility assurance and real-time delta pricing (`+$149.00`).

### Dedicated Specialized Components
- **Bottleneck & Compatibility Meter:** A horizontal segment bar featuring smooth emerald (`#10b981`), amber (`#d97706`), or violet statuses confirming PSU headroom, physical clearance, and PCIe bandwidth.
- **FPS / Thermal HUD Inspector:** Compact, high-tech card modules mimicking precision in-game overlays to display tested framerates across benchmark titles at 1440p and 4K resolutions.
